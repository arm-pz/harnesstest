# Task contract

- **Goal:** <one sentence: the outcome, not the activity>
- **Constraints:** <what must not change, e.g. "keep auth as is, no schema changes">
- **Deliverable:** <e.g. "a reviewable pull request on branch X">
- **Done when:** <checkable conditions, e.g. "`scripts/gate.sh` prints GATE: PASS; event `signup_completed` fires; desktop and mobile flows pass review">
- **Needs approval:** <actions that wait for a human, e.g. "anything touching production, sending messages, merging">
- **Budget:** <max attempts per failing step (default 3), time, spend>
- **Stop and ask if:** <e.g. "the done-when conditions conflict, a required file is missing, a fix needs a change listed under Constraints, or the same failure repeats twice">
